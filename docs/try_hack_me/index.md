# TryHackMe CTF Writeups

Welcome to my collection of TryHackMe laboratory writeups and CTF walkthroughs. These writeups capture my methodology, attack vectors, privilege escalation paths, and key takeaways across different domains of cybersecurity.

---

## Categories & Writeups

### Reverse Engineering
* **[Basic Malware RE](/try_hack_me/reverse_engineering/basic_malware_re/)**: Static analysis of obfuscated binaries, string extraction, and entry point inspection.
* **[Dear QA](/try_hack_me/reverse_engineering/dear_qa/)**: Binary exploitation lab involving stack buffer overflow and target address redirection.
* **[Security Footage](/try_hack_me/reverse_engineering/security_footage/)**: Reconstructing video frames from raw TCP stream packet captures using custom Python parsing and video compilation scripts.

### Web Exploitation
* **[Pickle Rick](/try_hack_me/web_exploitation/pickle_rick/)**: Web application recon, command injection, source code inspection, and file retrieval.

### Privilege Escalation
* **[Agent T](/try_hack_me/privelege_escalation/agent_t/)**: Enumeration of vulnerable web server headers leading to root-level system access.

### Server-Side Template Injections (SSTI)
* **[MD2PDF](/try_hack_me/server-side_template_injections/MD2PDF/)**: Exploiting PDF generator engines through server-side template injection to read local system files.

### Cryptography
* **[W1seguy](/try_hack_me/cryptography/w1seguy/)**: XOR cipher analysis and automated key recovery script development.

### Directory Traversal
* **[Corridor](/try_hack_me/directory_traversal/corridor/)**: IDOR and hash analysis to bypass authorization checks on endpoint paths.

### Subdomain Takeover
* **[Take Over](/try_hack_me/subdomain-takeover/take_over/)**: DNS record auditing and identifying dangling CNAME records for subdomain hijacking.

### OSINT
* **[Operation Slither](/try_hack_me/OSINT/operation_slither/)**: Open source intelligence investigation using metadata analysis and digital footprint tracing.
