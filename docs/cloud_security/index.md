# Cloud Security Architecture & Research

Welcome to the Cloud Security section. This area is dedicated to notes, architectural patterns, identity & access management (IAM) strategies, and attack path writeups in public cloud environments (AWS & Azure).

---

## Key Focus Areas

* **Identity & Access Management (IAM)**: Auditing cloud policies, permission boundaries, role assumption chains, and privilege escalation paths.
* **Cloud Infrastructure Security**: Hardening VPC networks, security groups, S3 bucket permissions, and API endpoints.
* **Threat Detection & Logging**: Monitoring AWS CloudTrail, GuardDuty, and Azure Sentinel for suspicious administrative actions.
